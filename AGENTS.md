# GitHub Portfolio

## Project

Personal developer portfolio / business card hosted on GitHub Pages.

The website must be a fully static website with no build step.

## Stack

Use only:

* HTML5
* CSS3
* Vanilla JavaScript

Do not use React, Vue, Angular, Svelte, TypeScript, npm, Vite, Webpack or other frameworks/build systems.

## Structure

```text
index.html
style.css
script.js
assets/
```

Keep HTML, CSS and JavaScript separated.

## Design

Create a premium dark developer portfolio.

Style:

* minimalistic
* modern
* professional
* visually impressive
* strong typography
* subtle glow effects
* smooth animations
* polished hover states
* responsive design

Avoid excessive effects, visual clutter and generic template design.

## Code Quality

Follow Clean Code principles.

Apply SOLID principles where they make sense, but do not over-engineer a small static website.

Use:

* meaningful names
* small focused functions
* minimal duplication
* clear separation of responsibilities
* semantic HTML
* CSS custom properties
* consistent formatting

Naming:

* CSS/HTML: `kebab-case`
* JavaScript: `camelCase`
* Classes: `PascalCase`
* Constants: `UPPER_SNAKE_CASE`

Use `const` by default and `let` when reassignment is required. Never use `var`.

## Development Order

Follow this order:

1. Concept
2. HTML structure
3. Visual design
4. Content
5. Interactions and animations
6. Responsive design
7. Visual polish
8. Final verification

Do not focus on animations before the basic structure and design are stable.

## Editing Rules

Before changing code:

1. Inspect the existing implementation.
2. Understand the current structure.
3. Make the smallest reasonable change.
4. Preserve existing functionality.
5. Do not rewrite unrelated code.

## GitHub Pages

The website must work directly on GitHub Pages.

Use relative paths for local assets.

Do not use backend code, server-side features or local filesystem paths.

## Final Check

Before considering a task complete:

* check HTML/CSS/JS for errors;
* check browser console;
* check links and assets;
* check desktop and mobile layouts;
* check accessibility;
* check for horizontal overflow;
* verify GitHub Pages compatibility.
